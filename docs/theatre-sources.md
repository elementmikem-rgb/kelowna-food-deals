# Theatres and performance halls by region: where their events can be read

Researched by hand in Chrome (Google search per region, then the venue's own site), 2026-11-05. "Platform" is the ticketing system the venue's own events page or Google result points at. This is a research list, not a scraper: nothing here is loaded yet unless the region already has Box Office, Showpass or Ticket Seller events (see project_todaystab_theatre_event_feeds_nov5 in memory).

How to read the platform column: a platform that serves many venues with the same page layout is worth one scraper (Tessitura web, TixHub, TicketScene, eVenue, Ticketpro). A venue-only site is a one-off.

## Platforms found, by how many venues use them (candidates for one scraper each)

- Tessitura web ("/Online/default.asp", "/Online/article/..."): Brampton Rose, Oshawa Regent, St. Catharines FirstOntario PAC, Richmond Hill Centre.
- eVenue (*.evenue.net): Kitchener Centre in the Square, Ottawa Meridian Theatres, Lethbridge Yates.
- Ovation (ovation.ca/<venue id>/...): five Quebec venues found.
- TixHub (secure1.tixhub.com/<venue>): Collingwood, Gravenhurst.
- TicketScene (ticketscene.ca/venues/<id>): Cambridge, Picton.
- TicketAcces: Val-d'Or, Rouyn-Noranda, Lévis.
- Tuxedo Billet: Montreal's Théâtre Outremont, Moncton Capitol.
- Ticketpro: Barrie Georgian Theatre, Spruce Grove Horizon Stage.
- Ticketmaster: Brossard, Quebec Capitole, Banff Centre links (no public listing; not a source to read).

Not covered here: regions that already have some theatre events from Showpass but thin coverage (for example Toronto, Montreal core, Halifax, Winnipeg, Edmonton, Calgary). The big halls there (Roy Thomson, Place des Arts, Winspear, Arts Commons) mostly use their own systems or Ticketmaster.
